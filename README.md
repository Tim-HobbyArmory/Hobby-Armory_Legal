# Hobby-Armory_Legal
Legal pages for Hobby Armory, served by GitHub Pages at https://legal.hobbyarmory.de.

Each page holds both languages (`.l-de` / `.l-en`); `assets/legal.js` switches between them
and builds the contents list, `assets/legal.css` carries the website's design tokens.
The German text is the binding version. Keep the slugs (`/impressum`, `/datenschutz`,
`/agb`, `/disclaimer`, `/delete-account`): the app, the stores and the website link to them.
